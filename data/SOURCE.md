# Data source

`miri_phasecurve_spectral_results.txt` is downloaded, unmodified, from
Zenodo record **10.5281/zenodo.7703086** ("GJ 1214b MIRI phase curve
analysis", Kempton et al. 2023), file `result.txt`.

Retrieved: 2026-08-11, via `https://zenodo.org/api/records/7703086`.

Whitespace-separated columns (header row present, prefixed with `#`):
`min_wavelength`, `max_wavelength` (micron), `A_med`/`A_lower_err`/`A_upper_err`
(phase-curve amplitude), `phi_med`/`phi_lower_err`/`phi_upper_err` (phase
offset), `Fp_med`/`Fp_lower_err`/`Fp_upper_err` (dayside planet/star flux
ratio), `RpRs_med`/`RpRs_lower_err`/`RpRs_upper_err` (fitted Rp/Rs),
`night_Fp_med`/`night_Fp_lower_err`/`night_Fp_upper_err` (nightside
planet/star flux ratio), `lnprob`.
